01 — About

Who I am

I'm Jimmy, a full stack developer focused on building complete web applications from the interface to the database. I like learning by shipping: designing the UI, connecting APIs, storing real data, and improving the experience until it feels useful.

My final project, CodeChat, is an offline AI coding tutor powered by local language models. It runs entirely on your machine — no internet, no API costs, no data leaving your computer.

I'm interested in developer tools, AI-assisted learning, and local-first software. I care about readable code, clear user feedback, and building projects that solve a real problem instead of just showing a feature.
